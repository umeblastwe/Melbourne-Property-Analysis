# Melbourne Housing Market Analysis (2016–2018)

## 📊 Project Overview
[cite_start]This project provides a comprehensive analysis of the Melbourne housing market using data from **2016 to 2018**[cite: 3]. [cite_start]The goal was to uncover key trends in property sales, regional performance, and the impact of physical and geographical attributes on property pricing[cite: 8, 108].

## 🛠️ Tech Stack
* [cite_start]**Database Management:** MySQL (for complex data querying and transformation)[cite: 6].
* **Data Visualization:** Power BI (for interactive dashboarding).
* **Documentation:** Microsoft PowerPoint.

## 🔍 Key Business Questions Answered
* [cite_start]**Market Concentration:** Which councils and regions have the highest sales volume? [cite: 11, 13]
* [cite_start]**Pricing Drivers:** Does proximity to the Central Business District (CBD) or the number of rooms significantly impact property value? [cite: 14, 15]
* [cite_start]**Sales Performance:** What is the overall market clearance rate, and which months see peak sales activity? [cite: 17, 19]

## 📈 Key Insights from the Dashboard
* [cite_start]**Distance vs. Price:** Properties in the **Inner Area** (within 5km of the CBD) command the highest average price ($1.15\text{M}$), with values decreasing as distance increases into the Middle and Outer Areas[cite: 91, 111, 112].
* [cite_start]**Sales Leaders:** **Boroondara City Council** leads in sales volume with **2,619** properties sold[cite: 69, 70].
* [cite_start]**Clearance Rate:** The market maintains a strong **75.69%** clearance rate, with **26,382** total properties sold during the period[cite: 147, 148].
* [cite_start]**Seasonality:** **September 2017** was the peak performance month, reaching a total sales value of over **$1.21\text{bn}$**[cite: 158].
* [cite_start]**Room Correlation:** While prices generally increase with the number of rooms up to a point, properties with **16 rooms** reached a peak average price of **$5\text{M}$**[cite: 134].
