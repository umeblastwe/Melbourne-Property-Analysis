# 🏢 Melbourne Property Market Analysis - Power BI Project

## 📌 Project Overview
An end-to-end Business Intelligence and Real Estate Valuation project analyzing property markets across Melbourne. This project examines housing prices, property types, seller distributions, yearly sales trends, and the direct impact of architectural configurations (bedrooms and bathrooms) on property values using an interactive Power BI dashboard.

---

## 📊 Dashboard Metrics & Key Insights

### 1. Core Summary Metrics
* **Total Suburbs Covered:** **349** suburbs analyzed[cite: 8].
* **Total SellerG Agencies:** **383** real estate agencies tracked[cite: 8].
* **Financial Benchmarks:**
  * **Median Price:** **$870.00K**[cite: 8].
  * **Price per SqM (Building):** **$16.62K**[cite: 8].
  * **Price per SqM (Land):** **$1.58K**[cite: 8].
  * **Price Variance %:** **-0.17**[cite: 8].

### 2. Property Distribution & Agency Performance
* **Total Properties by Type:** Visualized via a donut chart showcasing market share across property types (Houses, Units/Apartments, and Townhouses/Land)[cite: 8]. Houses dominate the majority share at **68.8%** (approx. 24K properties)[cite: 8].
* **Total Properties by SellerG:** A descending bar chart highlighting top-performing real estate agencies in Melbourne (such as Jellis, Nelson, Hockingstuart, and Ray White) by property listings volume[cite: 8].

### 3. Sales Trends Over Time
* **Total Sales by Year:** Line chart illustrating historical transaction volume trends between 2016 and 2019, reflecting market activity peaks and fluctuations[cite: 8].

### 4. Impact of Bedrooms & Bathrooms on Price
* **Matrix Analysis:** A detailed cross-tabulation matrix measuring median pricing behavior based on the combination of Bedrooms (Rows 1–4+) and Bathrooms (Columns 1–7)[cite: 8].
* **Key Finding:** Property prices scale predictably with an increase in room counts, showing clear valuation spikes for properties featuring 4+ bedrooms and multiple bathrooms (reaching upwards of $2.4M+ depending on configuration)[cite: 8].
